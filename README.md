# Kiwoom OpenAPI 프로젝트

키움증권 OpenAPI 연동 작업의 진행 상황을 공유하기 위한 저장소입니다.

---

## 폴더 구조

```
Kiwoom-Github-Active-Project/
├── kiwoom/              # 런타임 패키지
├── examples/            # API 예제 코드
├── examples_prove/      # 예제 실행 증적
├── generator/           # 각종 자동 생성기 (예제 코드, Postman 등)
├── convention/          # 코드 컨벤션 문서
└── postman/             # Postman Collection
```

### `kiwoom/`

> API 호출에 필요한 인증, 페이지네이션, 에러 처리 등의 공통 로직을 각 예제마다 반복하지 않기 위해 별도 패키지로 분리했습니다.

인증(토큰 발급/관리), REST 클라이언트, WebSocket 클라이언트를 포함합니다.
`examples/`의 모든 예제가 이 패키지에 의존합니다.

### `examples/`

> 하나의 파일만 실행하면 해당 API의 동작을 바로 확인할 수 있는 실행 단위를 제공하기 위해 작성했습니다.

`{카테고리}/{서브카테고리}/{함수명}.py` 구조로 정리되어 있습니다.

```
examples/
├── 국내주식/
│   ├── 종목정보/        # 시세, 거래원, 호가 등
│   └── 계좌/            # 예수금, 잔고, 주문 내역 등
└── OAuth 인증/
    ├── 접근토큰발급/
    └── 접근토큰폐기/
```

### `examples_prove/`

> 코드만으로는 실제 동작 여부를 알 수 없으므로, 실행 결과를 증적으로 남겨 정상 동작을 확인할 수 있도록 했습니다.

`examples/`를 실행한 출력 결과를 API별 `.txt` 파일로 저장합니다.

### `generator/`

> API가 수십~수백 개이므로 수작업 시 실수와 비효율이 발생합니다. 스펙으로부터 일괄 생성하여 일관성과 작업 효율을 확보하기 위해 만들었습니다.

API 스펙 데이터를 입력받아 예제 코드, Postman Collection 등을 자동 생성하는 스크립트 모음입니다.

### `convention/`

> 생성기의 출력 규칙과 수동 수정 시 따라야 할 패턴을 명문화하여 코드 품질의 일관성을 유지하기 위해 작성했습니다.

폴더 구조, 파일명, 파이썬 내부 구조 등 `examples/` 코드의 작성 규칙을 정의합니다.

### `postman/`

> 파이썬 환경 없이도 API를 빠르게 호출해볼 수 있도록 제공합니다.

Postman으로 import하여 사용할 수 있는 Collection 파일입니다.

---

## 실행

개발 환경의 표준 실행 방식은 `uv run`입니다.
